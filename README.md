# 牛来大冒险 3D · Ox is Coming

牛来（Ox Alpha）独闯四海，踩爆 **牛模王**（一个成精的 AI 模型）——
Three.js 3D 马里奥式平台跳跃，零依赖，点开即玩。

## ▶ 游玩地址

**https://mcapricorns.github.io/niu-lai-3d/**

> 双击打开即玩，无需安装；支持手机触屏。

## 🎮 玩法

- 5 大世界 · **20 关**（第 5 世界 Boss 关 5-4「Anthropic 的办公室」挑战 Anthropic Dario 真身，每关结尾另有牛模王分身拦路）
- 马里奥式物理：加速 / 急刹打滑 / 空中惯性 / 按住跳更高
- 空中连踩出 **COMBO 倍分**，全速冲刺可 **撞飞** 小怪（金色气流 = 冲撞就绪）
- 吃牛奶变大 · 星星无敌 · 铃铛 +1 命 · 100 金币 +1 命
- 新机关：**碎板**（踩上就塌）/ **火球炮台** / **大金币**（+500）易碎浮板
- 每关专属特色机关段：弹簧塔 / 云雀走廊 / 移动平台交叉 / 尖刺窄桥 / 弹跳长廊 …

## 🤖 牛来模式（AI 全自动）

- 按 **O**（或标题按 **A**）开启：牛来无敌、穿墙、碰谁谁死、掉坑自动回升，一气通全关（含 Boss）
- 游戏内 HUD 会显示「牛来模式 无敌闯关中」徽标

## ⌨ 操作

| 按键 | 功能 |
|---|---|
| ← → / A D | 移动 |
| 空格 / ↑ / W / Z | 跳跃（按住跳更高，松开截断） |
| Shift / X | 冲刺（全速可撞飞敌人） |
| M | 静音 |
| P / Esc | 暂停 / Esc 再按退回选关 |
| R | 重开本关 |
| O | 牛来模式开关 |
| 标题 A | 直接观看牛来全自动通关 |
