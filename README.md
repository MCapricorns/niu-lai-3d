# 牛来大冒险 3D · Ox is Coming

牛来（Ox Alpha）独闯四海，逐关踩爆 **GPT 老板**，最终闯进 **Anthropic 机房**挑战 Dario——
Three.js 3D 马里奥式平台跳跃，零依赖，点开即玩。

## ▶ 游玩地址

**https://mcapricorns.github.io/niu-lai-3d/**

> 双击打开即玩，无需安装；支持手机触屏。

## 🎮 玩法

- **v2.1.0 关卡个性重制 · 8 大世界 · 9 关**（8 标准关卡各 1 枚金蛋 + 终章 Boss 决战）：选关改为可扩展的
  大卡片 + 关卡轨道，先展示本关核心动作、难度、提示与通关/金蛋进度；关卡变多时会自动分页，不再把名称挤成小格子
- 8 个标准关卡各有专属考题：**刺缝入门** / **炮火节拍** / **冰湖棋盘** / **熔岩竖井** /
  **失重塔楼** / **双子摆渡** / **骗子乐园** / **炼丹冲刺**。布局借鉴 **I Wanna Be The Guy 系列**的
  "试错—掌握"循环：每段障碍只考一件事，失败原因可读，段与段之间留出观察与呼吸空间
- 经典跳刺元素：**刺坑**（跳不过就死）· **顶刺禁跳道**（敢跳就见血）· **40px 窄板**浮渡刺海 ·
  **假地板碎板**（看起来安全）· **弹簧枪毙陷阱**（要么弹上天堂要么弹进地狱）·
  **蹬墙摘金蛋**（塔间井底/岩浆上）· **炮压刺阵**（弹丸与尖刺抢你的落点）
- 手机竖屏会把游戏画面固定在顶部，并将触控拆成左右两个手区：左侧移动、右侧跳跃/冲刺/重击；
  选关、暂停与结算页自动隐藏触控键，不会再叠在按钮上
- **敌人领土制**：每关只有 1-3 只地面怪，各自独占巡逻区，周身 3 格无刺/坑/炮/岩浆，
  巡逻边界用台阶/岩石物理锁死——怪不越界，你被撞是时机问题，不是运气问题
- 敌人模型与碰撞盒同步加大 32%：狼/豹/鸦/炮台重新建模比例，一眼看得清死得明白
- v1.12 保留：**Boss 决战重做**（紧凑竞技场 · 预警→攻击→护盾解除循环 · **奶弹自动射击**）
- v1.11 保留：**地图引擎体素合并网格** + 环境光遮蔽
- v1.10 保留：**全关卡开放**，选关页任意直玩，通关/金蛋标记保留
- 马里奥式物理：加速 / 急刹打滑 / 空中惯性 / 按住跳更高
- 空中连踩出 **COMBO 倍分**，全速冲刺可 **撞飞** 小怪（金色气流 = 冲撞就绪）
- 吃牛奶变大 · 星星无敌 · 铃铛 +1 命 · 100 金币 +1 命
- v1.9 保留：**坐地重击**（空中 ↓ 砸穿砖/踏穿碎板/坐晕敌人）、**蹬墙跳**（贴墙连跳冲高）
- 金蛋收集：每关藏 1 颗 **金蛋**（危险位置，如板间悬空、岩浆井口），捡齐 9 颗解锁「金蛋大满贯」彩蛋

## ⌨ 操作

| 按键             | 功能                                     |
| ---------------- | ---------------------------------------- |
| ← → / A D        | 移动                                     |
| 空格 / ↑ / W / Z | 跳跃（按住跳更高，松开截断）             |
| Shift / X        | 冲刺（满速冲跳 ≈9.8 格,很多刺海靠它）    |
| ↓ / S（空中）    | 坐地重击：震地、砸砖、踏穿碎板、坐晕敌人 |
| 贴墙 + 跳跃      | 蹬墙跳：一蹬一跳冲上高处                 |
| Boss 战自动开火  | 牛来奶弹自动瞄准轰 Boss，专注躲攻击即可  |
| M                | 静音                                     |
| P / Esc          | 暂停 / Esc 再按退回选关                  |
| R                | 重开本关                                 |

## 🐂 角色

- **牛来**：芥末黄杂毛、蓝弯角、灰紫厚唇、白手套、下垂倦眼——照海报 1:1 程序化建模
- **GPT 老板**：深蓝西装、金冠、红色发光眼与 GPT 算力光环；守在旗门终点
- **Anthropic Dario**：终局西装金边眼镜 CEO。数据光束 / 弹幕齐射 / 冲撞眩晕 / 飞砸地震波——
  每次攻击后**护盾解除**，期间牛来**自动奶弹**输出（也可踩头）；残血进入「数据洪流」三阶段

## 🛠 维护

- 关卡排列全部集中在 [`levels.js`](levels.js)，修改地图无需进入游戏主循环；地图渲染引擎在 [`mapengine.js`](mapengine.js)
- v2.1 布局规则（levels.js 头部注释）：每段障碍单一意图、物理标定、敌人领土制、
  Boss 坪台 flagX-7..flagX 绝对干净——改地图时请遵守
- `npm install` 后运行 `npm run check` 检查格式和语法规则；运行 `npm test` 使用 Microsoft Edge
  对全 9 关执行固定种子 E2E（渲染/物理/射击/Boss 触发/每关 1 金蛋）
