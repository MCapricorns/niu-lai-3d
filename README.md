## ⌨ 操作

| 按键             | 功能                                     |
| ---------------- | ---------------------------------------- |
| ← → / A D        | 移动                                     |
| 空格 / ↑ / W / Z | 跳跃（按住跳更高，松开截断）             |
| J / F            | 奶弹射击：轰守关老板与终局 Boss          |
| ↓ / S（空中）    | 坐地重击：震地、砸砖、踏穿碎板、坐晕敌人 |
| 贴墙 + 跳跃      | 蹬墙跳：一蹬一跳冲上高处                 |
| Shift / X        | 冲刺（全速可撞飞敌人）                   |
| M                | 静音                                     |
| P / Esc          | 暂停 / Esc 再按退回选关                  |
| R                | 重开本关                                 |

## 🐂 角色

- **牛来**：芥末黄杂毛、蓝弯角、灰紫厚唇、白手套、下垂倦眼——照海报 1:1 程序化建模
- **GPT 老板**：深蓝西装、金冠、红色发光眼与 GPT 算力光环；守在各旗帜关终点
- **Anthropic Dario**：终局西装金边眼镜 CEO。**v1.12 重做**：数据光束（低位躲平台/高位贴地面）/ 弹幕齐射 / 冲撞撞墙眩晕 / 飞砸地震波——每次攻击后**护盾解除**，用奶弹(J)或踩头输出；残血进入「数据洪流」三阶段

## 🛠 维护

- 关卡排列、扩展段和安全路线集中在 [`levels.js`](levels.js)，修改地图无需进入游戏主循环；地图渲染引擎在 [`mapengine.js`](mapengine.js)。
- `npm install` 后运行 `npm run check` 检查格式和语法规则；运行 `npm test` 使用 Microsoft Edge 对全 32 关执行固定种子 E2E（渲染/物理/射击/Boss 触发）。
