# 牛来大冒险 3D · I Wanna Be The Ox

牛来（Ox Alpha）挑战一张 **I Wanna Be The Guy 式的连续跳刺大地图**：即死陷阱、存档点重生、
死亡计数，一路杀穿两位 GPT 老板守关，闯进克劳德机房打倒 Anthropic Dario——
Three.js 3D 精确平台跳跃，零依赖，点开即玩。

## ▶ 游玩地址

**https://mcapricorns.github.io/niu-lai-3d/**

> 双击打开即玩，无需安装；支持手机触屏。

## 🎮 玩法

- **v4.0.0 单一连续大地图**：没有选关、没有小关分段，一张 475 格长图从头走到尾。
  直接照抄 IWBTG 系列的流程骨架——**即死陷阱 · 存档点重生 · 死亡计数**，打倒终局 Boss 即通关
- **十一枚存档水晶**：散布在各大段落之间，碰到即存档；死亡后从最近的存档点满状态重来
  （世界机关同步重置），牛来短暂无敌防守尸；`R` 键随时回存档点重试
- **死亡计数**：没有生命上限、没有 Game Over、没有倒计时——死了就 +1，HUD 实时显示本次
  死亡数，累计死亡数持久保存，通关结算公布"本次死亡 N 次"
- **十六段考题，一段只考一件事**：刺缝入门 → 碎板假桥 → 炮火走廊 → 岩浆跳岛 → 弹簧陷阱
  （满弹上天堂，点弹才安全）→ 熔岩塔阶+蹬墙井 → 双子摆渡 → 碎板炮火复合 → 窄板刺海 →
  豹之领土 → GPT 老板守关 → 炮台阶梯 → 顶刺疾走 → 岩浆碎板桥 → 窄板之巅 → 二守 GPT →
  机房决战。段与段之间留呼吸平台，失败原因永远可读
- **默认全速**：没有冲刺键——移动就是原冲刺速度（跑跳 ≈8 格），起跳即冲
- **炮台平射弹**：炮弹贴地水平横扫，可以跳过、可以用掩体卡视线；碎板桥上躲弹是毕业考，
  高台炮塔的爬升线压制是新的加试
- **敌人领土制**：狼/豹各占一段巡逻区，周身 3 格无刺/坑/炮/岩浆，巡逻边界用台阶物理锁死——
  怪不越界，你被撞是时机问题，不是运气问题；全速奔跑直接撞飞小怪（金色气流 = 冲撞就绪）
- **Boss 决战（v4 大幅加强）**：Anthropic Dario 血量翻倍（26 格），攻击间隙更短、预警更快，
  新增**天顶弹幕雨**（只留两条安全缝）与**双段数据光束**（一道收、换行再来），三阶段冲撞
  撞墙还会震出冲击波；护盾解除窗口更短，贴身蹭伤已移除——躲攻击 = 生存，抓窗口 = 输出；
  两位 GPT 老板拦路，冲撞只能弹开、踩头与奶弹才能破防
- 马里奥式物理：加速 / 急刹打滑 / 空中惯性 / 按住跳更高；v4 起跳更快更跟手，
  短跳弧线更稳定，土狼时间 0.12s / 跳跃缓冲 0.14s
- **二段跳**（空中再按一次跳，带前空翻；落地或蹬墙补满）
- 空中连踩出 **COMBO 倍分**，里程碑掉无敌星星
- 道具都是真货：牛奶变大（多扛一下）· 星星无敌（弹簧陷阱柱顶）· 金铃铛加分（塔阶顶板）
- **坐地重击**（空中 ↓ 砸穿砖/踏穿碎板）、**蹬墙跳**（贴墙连跳冲高，蹬墙井必用）
- **HiDPI 高清渲染**：2D 画布与 Three.js 画布按设备像素比渲染，高分屏上文字与模型边缘不再发糊

## ⌨ 操作

| 按键             | 功能                                     |
| ---------------- | ---------------------------------------- |
| ← → / A D        | 移动（默认全速，起跳即冲）               |
| 空格 / ↑ / W / Z | 跳跃（按住跳更高，松开截断）             |
| 空中再按一次跳   | 二段跳：空中翻转再跳一截，落地/蹬墙补满  |
| ↓ / S（空中）    | 坐地重击：震地、砸砖、踏穿碎板、坐晕敌人 |
| 贴墙 + 跳跃      | 蹬墙跳：一蹬一跳冲上高处                 |
| Boss 战自动开火  | 牛来奶弹自动瞄准轰 Boss，专注躲攻击即可  |
| M                | 静音                                     |
| P / Esc          | 暂停 / Esc 再按返回标题                  |
| R                | 回到最近的存档点重来                     |

## 🐂 角色

- **牛来**：芥末黄杂毛、蓝弯角、灰紫厚唇、白手套、下垂倦眼——照海报 1:1 程序化建模
- **GPT 老板**：深蓝西装、金冠、红色发光眼与 GPT 算力光环；两段拦路（踩头/奶弹可破防，冲撞只会被弹开）
- **Anthropic Dario**：终局西装金边眼镜 CEO。数据光束（二阶段起**双段连射**）/ 弹幕齐射 /
  **天顶弹幕雨** / 冲撞眩晕（三阶段撞墙震出冲击波）/ 飞砸地震波——每次攻击后**护盾解除**，
  窗口更短，期间牛来**自动奶弹**输出（也可踩头）；残血进入「数据洪流」三阶段

## 🛠 维护

- 大地图布局全部集中在 [`levels.js`](levels.js)，修改地图无需进入游戏主循环；地图渲染引擎在 [`mapengine.js`](mapengine.js)
- 布局规则（levels.js 头部注释）：每段障碍单一意图、按真实物理标定跳跃距离、敌人领土制、
  存档点前后 2 格绝对干净——改地图时请遵守
- `npm install` 后运行 `npm run check` 检查格式和语法规则；运行 `npm test` 使用 Microsoft Edge
  对大地图执行 E2E（渲染/存档重生/死亡计数/物理回归/二段跳/炮台/Boss 触发/HiDPI）
