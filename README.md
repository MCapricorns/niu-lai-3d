# 牛来大冒险 3D：失落的星铃

昨夜的风暴打碎了唤来黎明的星铃。妈妈去了北坡接应迷路的人，牛来只带着家门口的一盏灯出发。他循着信标里的声音，和送信的阿檐、摆渡的老石一起找回星铃碎片，查清五个世界为何同时熄灯。

- [玩 v5.0.0](https://mcapricorns.github.io/niu-lai-3d/)
- [经典 v4.0.0 源码](https://github.com/MCapricorns/niu-lai-3d/tree/v4.0.0)

游戏在浏览器中直接运行，支持键盘和手机触屏。主线有五章、二十五幕，首次游玩的设计目标约为 40 分钟。实际用时取决于探索和重试次数。

## 玩法

- 在 3D 场景中前后左右移动，沿着金铃找起跳点和落脚处。短按可以小跳，长按可以跳得更高，空中还能再跳一次。
- 找齐本幕的信标，开启星门。每章最后一幕会找回一块星铃碎片，五章故事依次推进。
- 踩刺或掉下平台后，牛来会很快回到激活的检查点或关卡起点。本轮已点亮的信标和已收集的金铃、星星都会保留。
- 留心主路线外的星星。通关后可以重玩已解锁的关卡，挑战保存在当前浏览器的最佳用时。

## AI 演示

在标题界面选择「AI 演示」，可以观看牛来跳刺、搭乘渡台和点亮信标。想自己试时，点「接管」就能用键盘或触屏操控。剧情解锁和通关纪录采用独立的手动冒险进度。

## 操作

| 键盘               | 触屏     | 动作                           |
| ------------------ | -------- | ------------------------------ |
| `W A S D` 或方向键 | 方向摇杆 | 前后左右移动                   |
| `空格`             | 跳跃按钮 | 按住跳得更高，空中再按可二段跳 |
| `P` 或 `Esc`       | 暂停按钮 | 暂停                           |
| `R`                |          | 回到最近的检查点               |
| `M`                |          | 切换静音                       |

## 五个世界

| 章节     | 场景与挑战                                       |
| -------- | ------------------------------------------------ |
| 草浪起跑 | 穿过风车、果园和断渠，沿小路点亮山丘上的灯       |
| 赤砂回旋 | 从峡谷驿站进入采石场，抢在伸缩尖刺升起前换道     |
| 熔河摆渡 | 顺着熔岩谷重开两岸渡线，踩过会坍塌的琉璃板       |
| 云阶弹跳 | 借上升气流掠过云上遗迹，在听台接到妈妈的讯息     |
| 星核机房 | 从冷却渠爬上霓虹配电塔，穿过风暴涡轮井，重启星铃 |

各世界使用独立的远景画面，搭配随镜头变化的视差、地形雾和环境粒子。星铃复原后，机房上空会从夜色转入黎明。

## 开发

项目使用内嵌 Three.js，运行时无需安装依赖。开发时先运行 `npm ci`，再用 `npm run check` 检查格式与代码。`npm test` 运行关卡路线和 Chromium 浏览器测试，可用 `BROWSER_PATH` 指定浏览器的可执行文件。

| 剧情和章节顺序           | [story.js](story.js) · [campaign.js](campaign.js)                                      |
| 主关和扩展关布局         | [stages.js](stages.js) · [expedition.js](expedition.js) · [highlands.js](highlands.js) |
